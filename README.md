# Medical Document Maker

Android app pair for preparing, reviewing, and sharing user-selected medical-document test files and local device diagnostic reports. This is an independent utility and is not affiliated with any government department, CAPF organization, hospital, or official reimbursement portal.

## Apps
- Medical Document Maker: user-side app with local device checks and exportable test reports.
- Medical Document Maker Admin: separate viewer app that can import a report file explicitly shared by the user.

## Included test modules
- Local test entry screen (no real account authentication)
- Device model, Android version, battery and local permission posture
- Live network availability/type change monitor (no packet capture or browsing-history collection)
- APK static manifest permission review and signer SHA-256 display for a user-selected APK
- Opt-in Android runtime permission prompts for camera, microphone and location (sensors are not activated)
- Local test notification generated by this app
- Link to Android Notification Access settings for manual inspection; this build does not read other apps' notifications
- Android screen-capture consent prompt test; this build does not capture, save, or transmit screen frames
- Exportable local text test report
- Admin app can import a report file selected by the user; it does not silently connect to or control another device

## Safety and privacy
- No hidden operation, stealth persistence, credential/OTP collection, keylogging, private-message extraction, covert camera/microphone use, or remote control.
- No personal data is sent to a server by the test modules.
- APK analysis is static and permission-focused; it cannot certify that an APK is safe or malicious.
- Use only devices and files you own or are authorized to assess.
- This is a document/testing utility, not an official medical, government, hospital, or reimbursement service. Do not treat generated sample documents as medical advice or authentic certificates.

## Build
GitHub Actions builds separate debug APKs on pushes to `main` and on manual workflow dispatch.

Open **Actions → Android APK Build**, wait for a successful run, then download:
- `Medical-Document-Maker-user-debug-apk`
- `Medical-Document-Maker-admin-debug-apk`

Minimum Android version: Android 8.0 (API 26).
