# Reimbursement Claim

Android controlled security-testing lab for evaluating defensive tools such as SURAKSHA on devices owned or administered by the tester.

## Included modules
- Login-style entry screen with Force Type and test Login ID (local only; no real account authentication)
- Device model, Android version, battery and local permission posture
- Live network availability/type change monitor (no packet capture or browsing-history collection)
- APK static manifest permission review and signer SHA-256 display for a user-selected APK
- Opt-in Android runtime permission prompts for camera, microphone and location (the sensors are not activated)
- Local test notification generated by this app
- Link to Android Notification Access settings for manual inspection; this build does not read other apps' notifications
- Android screen-capture consent prompt test; this build does not capture, save, or transmit screen frames
- Exportable local text test report

## Safety and privacy
- No hidden operation, stealth persistence, credential/OTP collection, keylogging, private-message extraction, covert camera/microphone use, or remote control.
- No personal data is sent to a server by the test modules.
- APK analysis is static and permission-focused; it cannot certify that an APK is safe or malicious.
- Run tests only on devices and APKs you own or are authorized to assess.
- This is a testing utility, not an official CAPF portal and not a production reimbursement service.

## Build
GitHub Actions builds a debug APK on pushes to `main` and on manual workflow dispatch.

Open **Actions → Android APK Build**, wait for a successful run, then download the `Reimbursement-Claim-debug-apk` artifact.

Minimum Android version: Android 8.0 (API 26).
