# Reimbursement Claim

Android application starter project.

## First version
- Login screen with Force Type and Login ID fields
- Local-only validation and an informational OTP placeholder
- Privacy Policy information dialog
- No CAPF branding or official insignia
- No real authentication, SMS access, or OTP collection

## Build
GitHub Actions builds a debug APK on pushes to `main` and on manual workflow dispatch.

Open **Actions → Android APK Build**, wait for the run to finish, then download the `Reimbursement-Claim-debug-apk` artifact.

Minimum Android version: Android 8.0 (API 26).
